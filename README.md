# Загрузчик фотографий Cheyipai

CLI на TypeScript для сохранения фотографий осмотра автомобиля из отчёта Cheyipai. Раскладывает снимки по четырём категориям и переводит китайские названия на русский.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run download
npm run download -- "https://report.cheyipai.com/report-optimus-h5/index?reportCode=...&templateCode=...&reportVersion=..."
npm run download -- --help
```

Обязательны `reportCode`, `templateCode`, `reportVersion`. Без URL программа предлагает вставить ссылку.

Параметры: `--output ./photos`, `--no-translate`, `--overwrite`.
Результат сохраняется в `<output>/<код отчёта>/`, по умолчанию — в `photos/`.

## Результат и надёжность

Категории: `Exterior Photos`, `Paint Photos`, `Annotated Photos`, `Defect Photos`.
Повторяющиеся названия нумеруются. Существующие файлы пропускаются, если явно не передан `--overwrite`.
Запись идёт через временный файл; при ошибке он удаляется. Запросы ограничены таймаутом 30 секунд.
Ошибки отдельных фотографий не останавливают остальные загрузки, но дают ненулевой код завершения.

Встроенный `data/dictionary.json` содержит известные переводы. Неизвестные названия передаются Google Translate, результаты записываются в `.translation-cache.json`, исходный словарь не меняется. Если перевод недоступен, остаётся китайское название.

Утилита зависит от внешнего API Cheyipai и не является официальным клиентом. Изменение структуры отчёта может потребовать обновления. Используйте отчёты, к которым у вас есть доступ; не добавляйте реальные ссылки и фотографии в тесты или issues.

## Разработка

```sh
npm run typecheck
npm test
```

Тесты выполняются без реального отчёта и обращения к сервису перевода.
